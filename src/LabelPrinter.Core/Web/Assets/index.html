    Calibration help

    1. Load 4×6 labels, then press Test label. A frame should touch all four label edges.
    2. The GW block must be solid black. If it's white or the page looks inverted, toggle "GW graphics: 0-bits are black".
    3. Frame cut off on one side? Use the nudge arrows (X/Y offsets). 8 dots ≈ 1 mm.
    4. Labels skip or the printer feeds a few inches? The printer must re-learn the gap/label length. Follow the media calibration steps in the LP 2443 user guide, then print the test label again.
    5. Too light/dark: change Darkness. Smeared barcode: lower Speed.
    6. Scan the Code 128 on the test label with your phone or a handheld scanner.

    Phone printing

    Only paired phones can print and nothing else on this PC is exposed: not the printer port, file shares or this window. For printing from outside your home, don't open your router. Put a private network (Tailscale) or an authenticated tunnel in front. See the README.

    Findings

      Send a test

      Step 1 sends ~100 bytes of plain EPL2 text. If it prints, the whole path (queue → adapter → printer) works. Step 2 adds the graphics, barcode and frame.

      Windows queue

      Move queue to another USB port

      If you plugged the adapter into a different USB socket and Windows created a new port (USB002 …), point your queue at it. Windows will ask for administrator permission.

      Line-mode protection

      Status: –

      When on, every job begins with the "switch to label mode" command, so if the printer ever slips into Line Mode (printing code as text) it fixes itself on the next print. It turns on only after this test passes on your printer.

      Troubleshooting checklist

      • Adapter: USB into the PC, parallel end into the LP 2443's wide 36-pin Centronics connector (not the 9-pin serial). Printer powered on.
      • No USB00x port in Device Manager > Ports? Re-plug the adapter. See whether it appears under “Printers/USB Printing Support” or “Other devices”. Try a rear motherboard USB port, not a hub.
      • Queue offline / jobs stuck: power-cycle the printer, re-seat the adapter, then cancel stuck jobs and print the raw text test.
      • Prints the commands as text (N, q812, Q1218,24 …) followed by symbols: the printer is in Zebra's EPL Line Mode. Press “0. Fix prints code as text” once (sends ESC EPL2), power-cycle the printer, then run the raw text test.
      • Prints garbage characters: the queue's driver is converting the data. Use the “Generic / Text Only” driver with the RAW method.
      • Prints a blank label or the wrong colours: toggle “GW graphics: 0-bits are black”.
      • Moved the adapter to another USB socket: see “Move queue to another USB port”.
