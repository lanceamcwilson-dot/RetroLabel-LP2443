    📲 Print from the Share button (iPhone)

    Set this up once. After that, open any label PDF (Mail, Safari, Files, eBay…), tap Share → Print on LP2443, and it prints. Same Wi-Fi as the PC.

    1. Open the Shortcuts app → + (new shortcut). Name it Print on LP2443.
    2. Tap the ⓘ (info) button → turn on Show in Share Sheet. Set "Receives" to PDFs (or Files).
    3. Add action Get Contents of URL. URL:
    4. In that action tap Show More: Method POST. Headers: add Authorization = (starts with "Bearer").
    5. Request Body: File → pick Shortcut Input.
    6. Add action Show Notification with Contents of URL (shows "Printing 1 label…").

    The shortcut uses this phone's pairing key: if you "Forget this phone" or revoke it on the PC, set the header again. Android: the free HTTP Shortcuts app can do the same POST.

    Drag on the page. The area is scaled to fill the 4×6 label.
